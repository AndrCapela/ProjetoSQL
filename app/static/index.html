1. Ordem Lógica de Execução

              
Como o banco lê sua query (diferente da ordem que você escreve):

              
    
                
  1. FROM / JOIN (define as tabelas e junções)
    2. 
                
  2. WHERE (filtra linhas antes de agrupar)
    3. 
                
  3. GROUP BY (agrupa registros)
    4. 
                
  4. HAVING (filtra grupos após agregação)
    5. 
                
  5. SELECT (escolhe colunas e aliases)
    6. 
                
  6. ORDER BY → LIMIT (ordena e limita)
    7. 
              

            

            

              
2. JOIN vs LEFT JOIN

              
Use INNER JOIN quando só quer correspondências nos dois lados. Use LEFT JOIN para manter registros da tabela à esquerda mesmo sem vínculo (ex.: alunos sem matrícula, testando WHERE ad.id IS NULL).

            

            

              
3. Agregação & Arredondamento

              
SELECT d.nome, ROUND(AVG(n.nota), 2) AS media
FROM disciplinas d
JOIN alunos_disciplinas ad ON ad.disciplina_id = d.id
JOIN notas n ON n.aluno_disciplina_id = ad.id
GROUP BY d.id, d.nome
HAVING AVG(n.nota) >= 8.0;

            

            

              
4. CTE (WITH) & Window Functions

              
WITH ranking AS (
    SELECT nome, nota,
           RANK() OVER (ORDER BY nota DESC) AS pos
    FROM ...
)
SELECT * FROM ranking WHERE pos <= 3;

                  Extrair ano de data

                  Concatenar texto
                  a || ' ' || b

                  LIKE (maiús./minús.)
                  Case-insensitive para ASCII
                  Case-sensitive (use ILIKE)

                  Divisão de inteiros
                  5 / 2 = 2 (use * 1.0)
                  5 / 2 = 2 (use ::numeric)
                  5 / 2 = 2.5000 (use DIV para int)

                  INTEGER PRIMARY KEY AUTOINCREMENT

                  INT AUTO_INCREMENT PRIMARY KEY

                  GROUP_CONCAT(col, ', ')
                  STRING_AGG(col, ', ')
                  GROUP_CONCAT(col SEPARATOR ', ')
